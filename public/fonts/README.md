# Inter

Police de l’interface BOUSE, auto-hébergée et préchargée ; aucun appel à Google Fonts.

- Source : `@fontsource-variable/inter@5.3.0`, fichier `files/inter-latin-standard-normal.woff2`.
- Licence : SIL Open Font License 1.1, texte intégral dans [Inter-OFL.txt](Inter-OFL.txt).
- Intégrité SHA-512 de l’archive npm vérifiée avant extraction : `OupL48va4JNofb97w6NYeF9S7W/kHNKM0Er8Dem5nqi4jeOLrVJDoE8tZEpnMJmtkvNbB1EIPPwHcdkF6b1oUA==`.
- Axes variables : poids 100–900, taille optique 14–32, style normal. Le fichier est renommé `inter-latin-variable.woff2` sans modification des données.
- Sous-ensemble latin comprenant les caractères français, les ligatures œ/Œ et le symbole euro. Les indices techniques gardent la pile monospace ; le monogramme conserve Georgia.
- Les rôles de titres, de nombres, leurs graisses et leurs approches sont centralisés dans `src/tokens.css`.
